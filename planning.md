# JavaScript Todo App

## Goal

Build a Todo application using Vanilla JavaScript to practice DOM manipulation, events, Local Storage, and modular code organization.

## Features

- Add task
- Delete task
- Mark complete
- Edit task
- Search
- Filter
- Due date
- Priority
- Save to Local Storage

## Data Model

Each task contains:

- id
- title
- completed
- createdAt
- updatedAt
- dueDate
- priority
